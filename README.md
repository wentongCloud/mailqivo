# Mailqivo

Mailqivo is a local Codex plugin for drafting personalized email campaigns, reviewing recipient-specific previews, and following campaign results and replies.

## Install on macOS

Install and open the Codex desktop app. Install Node.js 22 or later and pnpm 11. The initial build downloads dependencies and fonts. Use a machine without an existing Mailqivo local marketplace or services when installing from a fresh checkout.

Download and extract the Mailqivo source archive from Releases, then run this command in the extracted directory.

```sh
zsh scripts/install-codex.sh
```

The installer starts the local database, API, and web console. It registers the local marketplace and installs Mailqivo in Codex. Keep the extracted directory in place while the services are registered.

Open Mailqivo from Codex. The administration console runs at [http://127.0.0.1:18090](http://127.0.0.1:18090). Use the local administrator password generated by the installer. Keep the populated `.env` private.

Use the [sample workspace](demo/README.md) for a preview without mail delivery. Before using a real mailing list, configure your own sending channel and sender identity, review consent and unsubscribe settings, and inspect a personalized preview.

## Uninstall on macOS

```sh
zsh scripts/uninstall-codex.sh
```

Read the uninstall prompts before choosing whether to remove local data.
